# ViperProvider
## Telecom Management Web App built with ASP.NET Core MVC
### ViperProvider is a role-based telecom management web application built using ASP.NET Core MVC.
### It integrates with a SQL Server database and provides different dashboards and functionalities for Admins, Clients, and Sellers.
-----

The application follows the Model–View–Controller (MVC) architecture:

- Model: Data and business logic
- View: User interface (Razor Pages)
- Controller: Handles requests and connects the View with the Model

ASP.NET Core MVC offers modern cross-platform support, clean structure, and easy integration with JavaScript.

-----
## Database 
The database is hosted locally and managed using SQL Server Management Studio (SSMS).
Entity Framework Core was used to scaffold the database into the project via: 
` Scaffold-DbContext -f "Server=localhost;Database=providerDB;Trusted_Connection=True;TrustServerCertificate=True" Microsoft.EntityFrameworkCore.SqlServer -OutputDir Models -Context "ProviderDBContext" -DataAnnotations `

-----
## Project Structure
### Models

- ProviderDBContext.cs — Database context configuration.
- Admin.cs, Bill.cs, Call.cs, Client.cs, Phone.cs, Programs.cs, Seller.cs, User.cs — Model classes generated by scaffolding.
- MetaData folder — Metadata classes providing user-friendly display names and attributes for MVC views.
- PartialClasses.cs — Maps metadata classes to their corresponding models.
- LoginModel.cs — Login form model.
- ClientDashboardViewModel.cs — ViewModel for the client dashboard.

### Controllers
Controllers fetch data from the database and render it in the Views.
They also define the behavior of the application based on user actions.

Examples include:
- UserController — Handles user listing, creation, deletion, and login logic.
- BillsController, ClientsController, ProgramsController, etc. — Provide CRUD fun

### Views
Home
- Index.cshtml — Main home page
- Welcome.cshtml — Personalized dashboard post-login

Entity Folders
Each table (Admins, Bills, Clients, etc.) has its own view folder containing:
- Index — Main page
- Create — Form for adding records
- Edit — Modify existing entries
- Delete — Confirm and delete a record
- Details — Display record details

User Dashboards
- Custom pages for:
- Admins
- Clients
- Sellers

Shared
- _Layout.cshtml — Global page layout
- Error.cshtml — Error handling page
- _ValidationScriptsPartial.cshtml — Form validation scripts
